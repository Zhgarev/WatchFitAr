# WatchFit AR, прототип 0.1

Android-приложение для **приблизительной примерки реального диаметра часов на фотографии собственного запястья**, с быстрым предпросмотром через камеру. Основной сценарий рассчитан на Samsung Galaxy S24 Ultra.

## Что работает в исходном коде

- Камера на базе CameraX, задняя камера, без подключения к серверу.
- Стоп-кадр с сохранением последнего снимка для повторного открытия.
- Каталог моделей в памяти устройства; загрузка JPG/PNG часов из галереи/файлов.
- Ввод бренда, модели, диаметра корпуса в мм и необязательного lug-to-lug.
- На фото часов двумя касаниями отмечается **диаметр самого корпуса**. Это необходимо: снимки разных продавцов масштабированы по-разному.
- Автоматическое удаление *однородного белого фона, соединённого с краями фотографии*. Для изображений с пёстрым фоном лучше подготовить PNG с прозрачностью заранее.
- Калибровка на стоп-кадре по двум меткам обычной линейки, расстояние вводится в мм.
- Экспериментальное автообнаружение напечатанного чёрного прямоугольника ровно **50 × 10 мм** (PDF в архиве). Перед применением требуется подтверждение, потому что тёмные вытянутые предметы могут дать ложное срабатывание.
- Перемещение часов касанием, поворот слайдером, просмотр и экспорт PNG в «Галерею / Pictures / WatchFitAR».
- Последний кадр и его масштаб сохраняются **как одна связанная с кадром сессия**. При новом снимке масштаб сбрасывается.

## Очень важное ограничение точности

Результат точен лишь настолько, насколько соблюдены исходные условия. Печатная полоска или линейка должны располагаться **рядом с рукой и на той же высоте относительно камеры**. Камеру держать приблизительно перпендикулярно плоскости циферблата. Снимай с небольшого расстояния, по возможности на **основную заднюю камеру 1×**, без цифрового зума и ультраширокого объектива. Вводи именно фактический диаметр корпуса, без головки. Чтобы оценить общее впечатление, дополнительно смотри на реальное lug-to-lug: сама программа сохраняет его в каталоге, но **не использует для геометрии**, поскольку измеряются только две точки диаметра.

В режиме живого предпросмотра размеры **не откалиброваны**. Точный по выбранному эталону масштаб применяется после фиксации кадра. При другом расстоянии до руки сделай новый кадр и откалибруй заново. Приложение не измеряет толщину запястья или 3D-перспективу, не гарантирует посадку по окружности и не является измерительным прибором.

## Сборка APK через Android Studio

1. Установи **Android Studio** на Windows/macOS/Linux (Android Studio включает JDK).
2. Распакуй ZIP, открой папку `WatchFitAR` как проект (**Open**).
3. При необходимости установи через SDK Manager Android SDK Platform **API 36**, Build Tools, а также настрой Gradle **8.13** (AGP **8.13.2**). В каталоге `gradle/wrapper` есть конфигурация версии Gradle; стандартный исполняемый Gradle Wrapper в архив не включён. В Android Studio при синхронизации выбери/скачай соответствующую локальную Gradle distribution.
4. Подключи S24 Ultra по USB, включи режим разработчика и «Отладка по USB». Нажми **Run** либо в меню **Build → Build APK(s)**.
5. Отладочный APK появляется в `app/build/outputs/apk/debug/app-debug.apk`. Передай его на телефон и установи, разрешив установку приложений из нужного источника.

Можно собрать без физического телефона, выбрав `Build APK(s)`; на S24 Ultra всё равно нужно проверить разрешения камеры, экспозицию, расположение наложения и измерительную погрешность.

> Важно: в среде подготовки проекта нет Android SDK и недоступна загрузка Gradle/Android-зависимостей. Поэтому APK и запуск на S24 Ultra **не были выполнены**, а исходники **не проходили полноценную Android-сборку**. Это MVP для компиляции и тестирования, а не проверенный магазинный релиз.

## Первый тест

1. Запусти и разреши доступ к камере.
2. Положи около запястья обычную линейку, чтобы было видно примерно 50 мм её шкалы.
3. Нажми «Кадр», затем «Линейка» и укажи расстояние **50**. Коснись меток 0 и 50 мм на снимке.
4. Нажми «+ Фото часов», выбери изображение, по двум касаниям отметь края круглого корпуса, введи реальный диаметр и сохрани модель.
5. Коснись запястья на кадре, передвинув центр часов. При необходимости поверни часы ползунком.
6. Нажми «Сохранить». Полученное фото появится в папке `Pictures/WatchFitAR`.

Для автоматической калибровки распечатай `reference_50mm.pdf` **без подгонки к странице, масштаб 100%**, измерь чёрную полосу настоящей линейкой, положи на один уровень с запястьем, сделай кадр и нажми «Авто 50 мм». Если детектор ошибается, используй ручную калибровку.

## Архитектура

`MainActivity` (CameraX и UI), `WatchOverlayView` (преобразование физического диаметра в пиксели), `PointPickerView` (диаметр корпуса на исходной фотографии), `MarkerDetector` (поиск 50×10 мм), `ModelStore` (каталог), `ImageUtils` (ориентация и очистка белого фона). Java 17, Android API 29+, CameraX 1.6.2. Данные остаются на устройстве.

## Что намеренно не делаем в 0.1

- Нет распознавания и отслеживания запястья нейросетью.
- Нет 3D-часов, теней, перспективной деформации ремня и окклюзии руки.
- Нет автоматического распознавания разметки произвольных бытовых линеек. Для них надёжнее две ручные точки. Автоматическая калибровка доступна только для специального чёрного эталона 50×10 мм.
- Нет облака и базы референсов.

## Сборка через GitHub Actions (без локального Android Studio)

В проекте есть файл `.github/workflows/build-apk.yml`. Загрузи **содержимое папки WatchFitAR** в GitHub-репозиторий, открой вкладку **Actions → Build Android APK → Run workflow**. При успешной сборке скачай артефакт **WatchFitAR-debug-apk**, внутри будет установочный APK. Требуется доступ к GitHub и публичным репозиториям Android. Этот workflow также ещё не запускался в среде подготовки проекта.
